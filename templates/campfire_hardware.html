Full-Surface Optics: Eliminating The Strip Light Flaw

Edge-To-Edge Luminescence
cancel

Why Internal LED Strips Look Wrong

  • Point Source Hotspots ("Digital Pepper"): Diodes spaced 7mm apart project bright circular cones onto the plastic with harsh falloff between dots.
  • Dark Corners & Black Seams: Diodes only fire perpendicular (120° cone). Chamfers, end-caps, and block corners receive zero direct flux, creating ugly black edges.
  • Hollow Shell Illusion: The eye immediately detects light bouncing inside an empty plastic container rather than radiant incandescent timber matter.
  • No Longitudinal Resolution: A strip is 1D. It cannot create realistic curling flame tongues wrapping around the 3D curvature of a facet.
check_circle

The Full-Surface Emitting Solution

  • 100% Luminous Surface Area: Every square millimeter of the log’s outer faces emits light. Zero dark borders, zero unlit joints.
  • Lambertian Volumetric Radiance: Light emanates evenly at all angles ($L = \text{constant}$), making the block look like a solid chunk of heated volcanic rock or compressed glowing embers.
  • Multi-Zone Per-Facet Addressing: Each face possesses independent 2D pixel resolution, allowing flames to swirl upwards while the base face radiates steady glowing heat.
  • Tactile Physical Integration: Smooth, seamless touch without exposed diode domes, sealed against dust and moisture.

Implementation Paths: Ready-Made vs. Bespoke DIY

Choose Your Build Strategy

Both ready-made commercial components and custom precision fabrication are completely viable. Here is how each path works in practice when connected to our Central Electronic Brain:

PATH 1: Ready-Made Commercial Modules FASTEST ASSEMBLY

Industrial stage-lighting, architectural luminescent bricks, and museum kinetic installations use standardized full-surface modular pixel blocks:

A. Architectural DMX/Art-Net 3D Pixel Cubes / Bricks Commercially available in 100mm, 150mm, and 200mm sizes (e.g. Kinetic Lights / Showtec / DMX 3D Pixel Bar blocks). Feature injection-molded frosted polycarbonate bodies with factory-calibrated 360° Lambertian emission. Equipped with standard DMX512 or Art-Net protocol decoding.
B. Mini-LED P2 / P2.5 Video Tile Prisms Ready-made indoor video display modules (128x128mm or 64x64mm pitch P2) connected via HUB75. When fitted with a continuous 3mm matte diffuser cap, each face becomes a high-density, video-rate dynamic surface capable of rendering authentic thermal eddy currents.
C. Commercial Smart Illuminator Bricks (e.g. Sisyphus / Nanoleaf Elements core) Repurposed modular smart fixtures designed specifically for edgeless ambient light blending.
Central Brain Hookup: The central brain connects via RS-485 transceiver or Ethernet Art-Net. Simply stream standard DMX universes directly into the modular chain.
PATH 2: Bespoke Precision DIY MAXIMUM CONTROL

For exact timber aspect ratios (long 4-sided timber logs, chunks, kindling) that mimic genuine split firewood:

A. Custom CNC Light Guide Plates (LGP) Order 4 laser-etched PMMA acrylic panels per log from optical acrylic suppliers (e.g. Ponoko or JLCPCB acrylic service). Edge-lit by high-CRI micro-COB strips tucked inside the mitered corners. Produces razor-thin, cold, 100% surface-emitting timber facets.
B. 4-Sided Rigid-Flex Facet PCBs Design a single cross-shaped flexible PCB with dense surface-mount SK6812 WWA or WS2812 mini-LEDs (1010 package). The board folds into the 3D rectangular log shape around a solid aluminum heatsink, topped with a seamless vacuum-formed frosted matte diffuser.
C. Cast Isotropic Optical Resin Blocks Cast frosted polyurethane resin mixed with 0.3% $BaSO_4$ (barium sulfate) scattering powder around an internal hollow light chamber. The entire block feels heavy, cold, and solid in the hand like stone or petrified wood.
Central Brain Hookup: An onboard $0.40 ATTiny1616 or RP2040-Zero inside each log receives high-speed UART / DMX packets and drives the local full-surface facet arrays.

Polarity-Agnostic Magnetic Interconnection

Foolproof Tactile Stacking

Seamless 360° Stacking Physics

Users will stack, flip, rotate, and cantilever logs in any orientation. The electrical and data connection must be 100% orientation-independent:

  1. Concentric Ring Magnetic Pogo Connectors: Center pin (Ring 0) carries 1-Wire discovery; Ring 1 carries Differential Data A; Ring 2 carries Differential Data B; Ring 3 carries DC Power Rail. Because each contact is a continuous circular ring, rotating the block around its axis never disrupts continuity.
  2. Dual Low-Drop Ideal Diode Rectifiers (LM74610 / MOSFET Bridge): If a log is placed upside-down, the power rails reverse without harm: onboard ideal diode MOSFET switches automatically route incoming 12V DC to the internal power rail with only a 0.03V forward drop (vs. 0.7V for lossy silicon diodes).
  3. Magnetic Latch & Snap: Countersunk N52 neodymium magnetic rings supply 1.8 kgf of holding force per facet, giving the stacked wood a satisfying tactile "snap" when docking.

3D Spatial Topology Discovery & Facet Mapping

How The Brain Locates Every Facet

In our 3D web simulator, block positions are known in code. In physical reality, when a user picks up a log and rests it diagonally at 45° across two other logs, how does the Central Brain know its spatial coordinate so flame eddies wrap across its surface seamlessly?

hub

Step 1: 1-Wire Silicon ID Adjacency Graph

Every docking face on every log contains a Maxim DS2401 64-bit Silicon Serial Number chip. When two faces touch, the Central Brain scans the 1-Wire line to immediately discover which face of Log A is resting on which face of Log B or the Plinth.

PLINTH_PORT_A ──> LOG_01 (South Face)
LOG_01 (Top Face) ──> LOG_03 (Bottom Face)
LOG_03 (North Face) ──> LOG_05 (Cantilevered Face)
screen_rotation

Step 2: 6-Axis Gravitational IMU Vectors

Each log incorporates a miniature 6-axis I2C accelerometer/gyroscope (LSM6DSOX or MPU-6050). At rest, the accelerometer reads the Earth’s gravity vector ($\vec{g} = [g_x, g_y, g_z]$), giving the Central Brain the exact roll and pitch tilt angle.

Tilt Vector: $\theta = \text{atan2}(-g_x, \sqrt{g_y^2 + g_z^2})$
Transformation: $[x,y,z]_{\text{world}} = \mathbf{R}(\theta,\phi) \cdot [x,y,z]_{\text{facet}} + \mathbf{T}_{\text{dock}}$

By pairing the Adjacency Tree with Kinematic Tilt Vectors, the Central Brain computes the exact 3D world coordinate of every single emitting surface pixel in space!

Volumetric Flame Math & Blackbody Engine

Central Brain 60 FPS Engine

Because each block is a 100% full-surface emitter, the Central Brain does not run static looped GIF animations. It evaluates a true mathematical 3D thermal field flowing continuously through the room:

1. 3D Simplex Convective Fluid

For each facet pixel at world space $(x, y, z)$, the thermal energy $T$ is computed using buoyant noise offsets:

T(x,y,z,t) = Simplex3D(x*fx, (y - v*t)*fy, z*fz)

Upward convection velocity $v$ produces organic rolling flame tongues that leap between adjacent logs.

2. Conductive Thermal Diffusion

Touching facet junctions transfer simulated caloric heat units:

dH/dt = k * (T_neighbor - T_self) - C_dissipate

Placing a cold new block onto glowing logs causes it to "ignite" over 3 to 5 seconds as heat conducts into it!

3. Planckian Blackbody Radiation

Thermal energy $T$ maps into realistic non-linear Planckian blackbody chromaticity:

T < 0.35: Charcoal Black (#140400)
T = 0.55: Crimson Ember (1800K)
T = 0.80: Radiant Amber (2400K)
T > 0.95: Plasma White Flame (3500K)

Central Brain Master Firmware (ESP32-S3 C++)

FastLED + Simplex Volumetric Voxel Dispatcher

Here is the central engine running on Core 0 of the ESP32-S3. It solves the 3D continuous fluid field and transmits packet frames over RS-485 / FastLED to every full-surface log node:

CentralHearthBrain.cpp Target: ESP32-S3 Core 0 (Arduino-ESP32 / ESP-IDF) 
#include <FastLED.h>
#include <SimplexNoise.h>

#define MAX_LOGS 12
#define FACETS_PER_LOG 4
#define VOXELS_PER_FACET 16
#define TOTAL_SURFACE_VOXELS (MAX_LOGS * FACETS_PER_LOG * VOXELS_PER_FACET)

// Central Brain Scene Graph: 3D Facet Voxel Map
struct SurfaceVoxel {
    float x, y, z;        // Absolute world coordinates (cm)
    float nx, ny, nz;     // Surface normal vector
    float coreHeat;       // Log core caloric level [0.0 - 1.0]
    uint8_t logId;
    uint8_t facetIndex;
};

SurfaceVoxel sceneVoxels[TOTAL_SURFACE_VOXELS];
CRGB surfaceFrameBuffer[TOTAL_SURFACE_VOXELS];
SimplexNoise simplex;

// Non-linear Planckian blackbody color radiation curve
CRGB blackbodyToCRGB(float temperatureKelvin, float radiance) {
    // 1800K (Crimson Ember) -> 2400K (Radiant Amber) -> 3200K (Golden White Flame)
    float t = constrain((temperatureKelvin - 1600.0f) / 1600.0f, 0.0f, 1.0f);
    uint8_t r = (uint8_t)(255 * radiance);
    uint8_t g = (uint8_t)(constrain(t * 185.0f, 0.0f, 185.0f) * radiance);
    uint8_t b = (uint8_t)(constrain(pow(t, 2.4f) * 75.0f, 0.0f, 75.0f) * radiance);
    return CRGB(r, g, b);
}

// 60 FPS Volumetric Solver: Samples continuous 3D field across all block surfaces
void computeVolumetricSurfaceFrame(float timeSec) {
    const float riseVelocity = 2.2f;    // Upward convection (cm/s)
    const float spatialScale = 0.075f;  // Turbulence spatial frequency
    
    for (int i = 0; i < TOTAL_SURFACE_VOXELS; i++) {
        SurfaceVoxel& v = sceneVoxels[i];
        
        // Compute upward traveling turbulence coordinate
        float sampleX = v.x * spatialScale;
        float sampleY = (v.y - (timeSec * riseVelocity)) * spatialScale;
        float sampleZ = v.z * spatialScale;
        
        // Multi-octave Simplex fluid noise
        float noise = simplex.noise(sampleX, sampleY, sampleZ);
        noise += 0.5f * simplex.noise(sampleX * 2.2f, sampleY * 2.2f, sampleZ * 2.2f);
        noise = (noise + 1.5f) / 3.0f; // Normalized [0.0, 1.0]
        
        // Height gradient: Lower blocks form glowing ember foundation; upper facets flicker
        float heightFactor = constrain(1.0f - (v.y / 50.0f), 0.18f, 1.0f);
        float thermalEnergy = noise * heightFactor * v.coreHeat;
        
        // Map thermal energy to Planckian blackbody color
        float kelvin = 1600.0f + (thermalEnergy * 1600.0f);
        float brightness = constrain(thermalEnergy * 1.35f, 0.04f, 1.0f);
        
        surfaceFrameBuffer[i] = blackbodyToCRGB(kelvin, brightness);
    }
    
    // Broadcast complete frame over high-speed RS-485 / FastLED bus to all full-surface blocks
    FastLED.show();
}
